# نظام التصدير — EgyGulf Export System

سجل طلبية واحد يطلع منه: عرض السعر، الـ PI، أمر الإنتاج، الفاتورة التجارية، قائمة التعبئة، إيصال الكاش، وطلب الشهادة الصحية (Word + إيميل + ZIP بالتحاليل).

## الملفات

| الملف | لازمته |
|---|---|
| `dist/index.html` | السيستم كله في ملف واحد (فيه اللوجو). ده اللي بيترفع. |
| `dist/config.js` | إعدادات Firebase وإيميل المدير. |
| `firestore.rules` | قواعد الحماية والصلاحيات. |
| `src/` + `build.py` | الكود الأصلي. لو عدّلت فيه شغّل `python3 build.py` عشان يطلع `dist` جديد. |

لو فتحت `dist/index.html` من غير ما تملا `config.js`، السيستم بيشتغل **وضع تجريبي** والبيانات بتتحفظ على المتصفح بس. ده كويس للتجربة.

## التشغيل الحقيقي (مرة واحدة)

1. **مشروع Firebase جديد** من console.firebase.google.com (الخطة المجانية Spark كفاية؛ الملفات بتتخزن جوه Firestore نفسه).
2. **Authentication** ← Sign-in method ← فعّل **Email/Password**.
3. **Firestore Database** ← Create database ← اختار أقرب منطقة (مثلًا `europe-west`).
4. **Project settings** ← Your apps ← أضف Web app ← انسخ `firebaseConfig` وحطه في `dist/config.js`.
5. حط **إيميل المدير** في مكانين:
   - `dist/config.js` في `adminEmails`
   - `firestore.rules` مكان `your_admin_email@example.com` (بحروف small)
6. **Firestore ← Rules**: امسح اللي موجود، والصق محتوى `firestore.rules`، واضغط Publish.
7. **النشر على Vercel**: ارفع `index.html` و`config.js` (من فولدر `dist`) على ريبو GitHub، واربطه بـ Vercel كمشروع static (من غير build command).
8. **Authentication ← Settings ← Authorized domains**: أضف دومين Vercel (مثلًا `egf-export.vercel.app`).

## أول استخدام

1. ادخل بإيميل المدير واعمل حساب، وهيتفتح على طول كمدير.
2. باقي الفريق يعمل حسابات، وهيفضلوا "مستنيين موافقة" لحد ما المدير يحدد دور كل واحد من صفحة **المستخدمين**.
3. املا بالترتيب: **الإعدادات** (بيانات الشركة والبنك والشروط) ← **المنتجات** (كود HS وأبعاد ووزن الكرتونة) ← **الدول** (المستندات المطلوبة لكل دولة) ← **تحاليل المنتجات** (شهادة الزراعة ونتيجة معمل الصحة لكل صنف) ← **شهادات الشركة**.

## الصلاحيات

| الدور | يقدر يعمل |
|---|---|
| مدير | كل حاجة، ويقدر يتجاوز أي قفل بسبب مكتوب في السجل |
| تصدير | الطلبيات، الشحن، المستندات، الشهادة الصحية، المنتجات، الدول، التحاليل، تسجيل الدفعات |
| مبيعات | الطلبيات والعملاء وعروض الأسعار |
| إنتاج | أمر الإنتاج، التشغيلات، رفع التحاليل |
| حسابات | تسجيل الدفعات و**تأكيد استلامها** |

## الأقفال

- مافيش **إنتاج** قبل تأكيد المقدم.
- مافيش **جاهز للتحميل** من غير رقم تشغيلة وتاريخ إنتاج لكل صنف.
- مافيش **تحميل** قبل تأكيد المبلغ كله، ورقم الحاوية والختم (والحجز والـ VGM لو مش EXW).
- مافيش **اتشحنت** قبل ما كل مستندات الدولة تبقى "اتعمل" أو "مش مطلوب"، والبوليصة.
